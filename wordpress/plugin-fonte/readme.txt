2. Plugins > Adicionar novo > Enviar plugin > time-trial-v2-ranking.zip > Instalar > Ativar.
3. O jogo abre em https://SEUSITE/timetrial/ (mesmo link de antes) e tambem em /timetrial-v2/.
4. Moderacao: Ferramentas > Time Trial V2 Ranking.
Se o plugin da V1 continuar ativo, a V2 abre so em /timetrial-v2/ (sem conflito).
