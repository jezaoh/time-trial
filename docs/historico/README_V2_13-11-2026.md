# Time Trial V2 — física de potência

> Para continuar em outra conversa, comece por **CONTEXTO.md**.

Versão separada da V1. Só o ciclista branco. O `time_trial_v2.html` avulso não tem ranking; a versão com ranking próprio
fica no plugin `wordpress/time-trial-v2-ranking.zip` (ver `docs/RANKING_WORDPRESS_V2.md`).
A V1 (`time-trial-pacote/`), o ranking oficial e o plugin da V1 não foram alterados.

## Como executar

| Quero… | Faça |
|---|---|
| Jogar | Abra `time_trial_v2.html` no navegador. |
| Mexer no código | `cd src && python3 -m http.server 8000` → `http://localhost:8000/` |
| Gerar o HTML único | `python3 tools/montar_arquivo_unico.py --saida time_trial_v2.html` (sem `--rank-api`) |
| Instalar no WordPress com ranking (substitui a V1) | `wordpress/time-trial-v2-ranking.zip` → desative o plugin da V1; jogo em `/timetrial/` (e `/timetrial-v2/`) |
| Simular o equilíbrio | `node tools/balanceamento/sim_v2.js` (toques, sprint, limites, corrida; compara com a V1) |
| Teste no navegador | `python3 tools/testes/teste_v2.py time_trial_v2.html /tmp` (gera capturas) |

Controles: iguais aos da V1. **Espaço / raio** = acelerador: pressionado, a potência sobe 320 W/s desde o 1º quadro a partir do
valor atual; solto, desce suave até 175 W. Barra: verde = stamina atual. A fadiga (interna) sobe sempre, limita o teto da stamina
e só água (−8 em 2 s, 5 garrafas) e gel (−40%, 2 géis) reduzem. Telas de vitória e de quebra com ilustração.

## O que mudou em relação à V1 (arquivos de `src/js/`)

| Arquivo | Mudança |
|---|---|
| `mecanica.js` | Potência contínua (teto 1.000 W), stamina por intensidade, fadiga de resistência + intensidade (sem recuperação passiva), água/gel, física de potência. Parâmetros no bloco `AJ` (ver `docs/MECANICA_V2.md`). |
| `desenho.js` | Linha `FTP 250 W · 160% (400 W)` acima da barra; barra: verde = stamina atual, vermelho = o resto (água com brilho azul); ilustrações nas telas finais; sprite escolhido pela potência (normal < 108% FTP · esforço 108–160% · sprint ≥ 160% · em pé em subida forte; limites em `SPR`); setas da seleção ocultas; textos de ajuda. |
| `paineis.js` | Troca de ciclista desativada quando só há 1. |
| `principal.js` | Pernas param na roda livre (potência ~0). |
| `audio.js` | Som de roda livre quando a potência ~0; chave `tt2_set`. |
| `compartilhar.js` | Novo: botão COMPARTILHAR na tela final (vitória e quebra), mensagem automática e card 1080×1920 com a ilustração; link em `SHARE_URL`. |
| `ranking.js` | Igual à V1 (liga só com `--rank-api`); chave `tt2_uid`. A versão do WordPress usa a API `timetrial2/v1`. |

Imagens, sons, CSS e `index.html` (só o título) são os mesmos da V1, mais `fim_venceu.webp`, `fim_quebrou.webp` e `p_b3.webp` (sprint, gerado por `tools/preparar_sprite_sprint.py`; `tools/preparar_sprites_branco_alternativo.py` alinha folhas novas pela bike, caso se queira trocar a animação) em `assets.js`.
`principal.js` também reinicia a animação da ilustração final.
